*diff.txt*	Show file diffs in a dedicated tab for Neovim.

==============================================================================
INTRODUCTION					*diff*

Diff Explorer opens a new tab with a file panel and two diff buffers. It reads
git, hg, and jj repositories. The panel lists changed files. Moving the cursor
to a file loads its baseline on the left and the working file on the right.
Both sides use Neovim diff mode, so `diffget`, `diffput`, and `:w` work.

The baseline buffer is read-only. The working buffer is a real file buffer.

==============================================================================
COMMANDS					*diff-commands*

:Diff [rev] [-- paths]			Open the diff view. Without a rev, compare
					working tree against HEAD, parent, or @-.
					A rev such as HEAD~2 sets the baseline.
					Paths after `--` narrow the file panel.

:DiffOpen [args]			Same as :Diff.

:DiffHistory [file]			Show commits that changed the file. The panel
					lists revisions. Selecting one loads that
					revision as the baseline.

:DiffMerge				Show conflicted files in a three-way view.
					Columns are ours, base, and theirs. The ours
					buffer is the real file. Write it to resolve.

:DiffFiles {left} {right}		Diff two arbitrary files in a new tab.

:DiffDirs {left} {right}		Diff two directories. The panel lists paths that
					differ in content or existence, including hidden
					files. Text sides are real file buffers, so :w writes
					through to disk. Binary files render as placeholders
					and are not loaded into buffers. The panel follows
					`listing_style` and `tree_style`. Selecting a folder
					clears the diff side. The tab title is
					"DiffDirs <left> <-> <right>".

:DiffDirsSwap			Swap the two directories in the active DiffDirs view.
					The panel root, status letters, tab title, and diff
					follow the new order. `s` in the panel does the same.

:DiffClose				Close the current Diff tab.

:DiffToggleFiles			Hide or show the file panel.

:DiffFocusFiles				Move focus to the file panel.

:DiffToggle				Alias for :DiffToggleFiles.

:DiffRefresh				Reload the panel entries.

:DiffNext / :DiffPrev			Move to the next or previous file. Crosses a
					page boundary when needed.

:DiffNextPage / :DiffPrevPage	Move to the next or previous panel page.

:DiffGotoPage {n}			Jump to panel page {n}.

In the panel, `]p` and `[p` move between pages. The panel winbar shows the
current page, page size, and root path. Press `K` on a file or folder row to
show its path relative to the panel root in a floating tooltip. The tooltip
closes when the cursor moves or the panel loses focus.

The two diff windows resize as one group. Resizing the panel redistributes the
remaining width equally between them. Resizing one diff window applies that
width to both. Merge mode keeps its own three-window layout.

In a Diff tab, other commands are blocked. `:e` becomes `:tabedit`, so the
Diff layout stays intact. Diff windows also set `winfixbuf`, so pickers and
other plugins cannot replace their buffers. Snacks picker jumps open the
selected file in a new tab while a Diff tab is focused. `:w`, `diffget`,
`diffput`, `do`, `dp`, and `diffupdate` still run. Opener commands such as
`:Diff`, `:DiffHistory`, and `:DiffDirs` work from any tab. Commands that
operate on an open view work only while that Diff tab is focused.

==============================================================================
PROFILES

working				Baseline is HEAD for git, parent for hg, @- for jj.
staged				Git only. Compare HEAD with the index.
unstaged			Git only. Compare the index with the working file.

Press `<Tab>` in the panel to cycle profiles. You can also pass specs to
`:Diff`:

	:Diff before=head after=worktree
	:Diff before=rev:HEAD~1
	:Diff before=@/path/to/other/repo

The `@/` form maps the current relative file path under another root.

==============================================================================
CONFIGURATION				*diff-config*

Call `require("default.plugin.diff").setup{}` in your config. A trusted
`.nvim.lua` in the project root can call `Diff.setup{}` to override values for
that project only.

	default_profile		"working"
	profiles		table of before and after specs
	listing_style		"list" or "tree"
	tree_style		"unicode" or "ascii"
	tree_indent		{ branch = 2, vertical = 3 }
	sticky_scroll		false
	page_size		100
	panel_width		40
	tab_title		"Diff"
	history_tab_title	"DiffHistory"
	merge_tab_title		"DiffMerge"
	diff_files_tab_title	"DiffFiles"
	diff_dirs_tab_title	"DiffDirs"
	redirect_commands	table mapping command names to tab-safe commands

`tree_indent.branch` sets the number of dash characters in `├──` and `└──`.
`tree_indent.vertical` sets the spaces after `│`.

Set `page_size` to 0 to show every entry again. Pagination keeps only one page
in the panel buffer. Directory scanning still walks every file before the view
opens.

Set `sticky_scroll` to true to pin the folder chain of the first entry as real
lines above the entries in the panel buffer. The header follows the first entry,
not the cursor, and is omitted on the first page and for entries at the top
level. Header lines are highlighted with `Comment` and are skipped by file
selection, so page navigation and cursor movement still address real entries.

Tab titles include the command arguments. For example, `:Diff HEAD~2 -- sub`
shows `Diff HEAD~2 -- sub` in the tabline.

==============================================================================
LIMITATIONS

The tree style lists changed files only, not the whole working tree. File
history uses the left panel, not a bottom log panel. Merge mode has three
columns and does not add a fourth base. Staging from the panel is not part of
this module. Jujutsu support follows the installed jj 0.7.1 command set.
